#  EPITA Lecture Notes

This repository contains lecture materials for **EPITA** courses.  
It includes notes, exercises, labs for **Master** and **Bachelor** programs in Data Visualization, Artificial Intelligence, Linux Operating System, and Statistics & Probability.

---

##  Data Visualization (Master, 21h)

Learn how to effectively represent and explore data through visualization. Topics include best practices, common pitfalls, and specialized tools.

- **Session 1:** Introduction to Data Visualization & Data Sources  
- **Session 2:** Good Practices & Common Pitfalls  
- **Session 3:** Matplotlib & Seaborn: Visualization Essentials  
- **Session 4:** Cartography & Geospatial Visualization  
- **Session 5:** Case Studies: Data Journalism  
- **Session 6:** Visualizing Multidimensional Data & Dimensionality Reduction *(Work on your project)*  
- **Session 7:** Project Presentation  

---

##  AI: Images and Videos (Master, 21h)

Explore computer vision techniques and AI models for image and video processing. Learn from fundamentals to advanced applications.

- **Session 1:** Introduction & Basics of Computer Vision 
- **Session 2:** Filtering, Edge Detection & Shape Detection  
- **Session 3:** Intro to PyTorch + CNNs for Classification  
- **Session 4:** Feature Extraction & Segmentation  
- **Session 5:** Object Detection & Optical Character Recognition  
- **Session 6:** Advanced Topics: Facial & Emotion Recognition, Tracking  
- **Session 7:** Project Presentation

##  AI: Audio and Signal (Master, 24h)
